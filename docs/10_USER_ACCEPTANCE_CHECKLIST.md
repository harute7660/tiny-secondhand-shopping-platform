## 5. 오류 화면과 정보노출 점검

- [ ] 발표·배포 환경에서 `DEBUG=False`임을 시작 로그 또는 설정 검사로 확인
- [ ] 존재하지 않는 URL은 TINY MARKET 404 화면이며 URL pattern 목록을 표시하지 않음
- [ ] 권한 없는 요청은 TINY MARKET 403 화면이며 내부 권한명·객체 ID를 표시하지 않음
- [ ] CSRF 없는 POST는 TINY MARKET 403 화면이며 CSRF reason·cookie 값을 표시하지 않음
- [ ] 잘못된 요청은 안전한 400 안내이며 Python 예외 문자열을 표시하지 않음
- [ ] 예상하지 못한 예외는 TINY MARKET 500 화면이며 복구 과정에서 다시 실패하지 않음
- [ ] 모든 오류 응답에 `Traceback`, `Exception Value`, `Python Path`, 절대경로, Django/Python 버전, settings, 환경변수, POST 비밀번호가 없음
- [ ] **[권장]** 429는 사용자에게 재시도 시점을 알리고 `Retry-After`를 제공함
- [ ] **[권장]** 405도 흰 화면·기본 영문 대신 서비스 문맥에 맞는 안내를 제공함
