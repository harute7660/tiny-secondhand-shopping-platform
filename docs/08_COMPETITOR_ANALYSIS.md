# 당근·번개장터 비교 및 제품 적용 결정

## 조사 방법과 해석 주의

- 조사 기준일: 2026-07-12
- 현재 기능은 각 회사의 공식 서비스·도움말·보도자료를 우선했다.
- 단점은 한국소비자원·공정거래위원회 자료와 공개 보도를 교차 확인했다.
- 회사가 발표한 사기 감소·거래 성장 수치는 자체 집계이며 독립 검증 수치처럼 표현하지 않는다.
- 과거 소비자 조사는 현재 개별 회사의 피해율이 아니라 중고거래의 구조적 위험을 설명하는 자료로만 사용한다.

## 보완하려는 단점과 구조적 위험

1. 지역 기반만 사용하면 희귀·취향 상품의 선택지가 줄어든다. 당근도 2026년 바로구매 매물의 전국 검색을 확대했다.
   - https://about.daangn.com/company/pr/archive/%EB%8B%B9%EA%B7%BC-%EB%B0%94%EB%A1%9C%EA%B5%AC%EB%A7%A4-%EA%B1%B0%EB%9E%98-%EB%B2%94%EC%9C%84-%EC%A0%84%EA%B5%AD-%ED%99%95%EB%8C%80/
   - 대응: 지역은 선택 필터로 두고 전체 상품 검색을 허용한다.
2. 평판·인증은 안전을 보증하지 않는다. 계정 탈취·대여와 비대면 선입금 위험이 남는다.
   - 대응: 평판 점수보다 권한·상태·원장·신고·증거 기록을 우선한다.
3. 안전결제 의무화는 구매자를 보호하지만 판매 수수료와 정산 대기라는 마찰이 생길 수 있다.
   - https://www.greened.kr/news/articleView.html?idxno=317185
   - 대응: 과제용 포인트에는 수수료를 두지 않고 즉시 원장 반영하되 중복·잔액 초과를 원자적으로 차단한다.
4. 상품 설명과 실제 상태 차이, 환불 거부, 미배송은 C2C의 구조적 분쟁이다.
   - https://www.kca.go.kr/webzine/board/view?div=kca_2208&linkId=445&menuId=MENU00307
   - 대응: 상태·하자 설명을 별도 입력하고 신고 상태와 관리자 검토를 남긴다.
5. 위해·거래금지 상품은 자동 필터만으로 해결되지 않는다. 공정위·소비자원 협약도 감시·차단·신고·악성 이용자 제재를 함께 요구한다.
   - https://www.kca.go.kr/home/sub.do?menukey=6081&mode=view&no=1003517453
   - 대응: 등록 안내, 신고, 상품 soft block, 계정 정지를 결합한다.
